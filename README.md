# Palette & Paper

Palette & Paper is a browser-first game project. Build 01 establishes the technical foundation only; there is no playable game yet.

## Local development

Requirements: Node.js 22.12+ and npm.

```bash
npm ci
npm run dev
```

Vite prints the local development URL after startup.

## Tests

```bash
npm test
```

## Production build

```bash
npm run build
```

The production bundle is written to `dist/`.
